🏦 Azure SRE Agent Demo

Production failures, on demand.

A demo banking application where realistic failure scenarios are embedded into normal banking workflows. Clicking buttons like "Generate Annual Statement" or "Run Fraud Detection" silently triggers production issues that Azure SRE Agent can detect, investigate, and mitigate.

Get started

Deploy everything in one command

Provision infra, build and deploy the app, configure monitoring, and import dashboards — all with azd up.

1

Clone the repo

Grab the source and move into the project directory.

# Clone & enter
git clone https://github.com/AlahmadiQ8/sre-agent-demo.git
cd sre-agent-demo
2

Deploy to Azure

One command provisions all resources and deploys the container.

# Infra + app + monitoring
azd up
3

Connect SRE Agent

Wire up the Grafana MCP endpoint and start an investigation.

# Get the MCP endpoint
azd env get-value \
  GRAFANA_MCP_ENDPOINT
